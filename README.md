# JULIA — Parfum

Landing page éditoriale pour annoncer la sortie de JULIA le 20 janvier 2027.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Expérience

- Préloader animé en Lottie avant l’arrivée sur la page.
- Flacon `public/parfum.glb` rendu en Three.js, présent pendant tout le scroll.
- Rotation du flacon liée à la progression de défilement.
- Compte à rebours jusqu’au lancement.
- Mise en page responsive, animations Motion et icônes Lucide.
